CafeWorking Site v19

Nesta versão:
- Formulários preparados para Netlify Forms
- Captura local de leads em localStorage para testes
- Admin Leads mostra os leads enviados na prévia local
- Formulários melhorados em Contato, Agendar Visita, Diagnóstico e Cadastro
- Campos nomeados para facilitar integração futura com CRM/Power Automate/WhatsApp

Para testar localmente:
1. Abra index.html
2. Envie um formulário em agendar-visita.html ou contato.html
3. Abra admin-leads.html para ver o lead capturado localmente

Para Netlify:
- Arraste a pasta do site para o Netlify
- Os formulários com data-netlify=true devem aparecer em Forms após o primeiro deploy/envio

Área para novos artigos

Modelo pronto para incluir novos conteúdos no blog.

Quando for publicar um novo artigo, crie uma nova página HTML e adicione um card no grid do blog seguindo este padrão.

Dados do novo artigo

  • Título: nome principal do artigo.
  • Categoria: coworking, endereço fiscal, empresa, jurídico, contabilidade etc.
  • Imagem: salvar em assets/img/blog/.
  • Resumo: até 2 linhas com promessa clara.
  • Arquivo: criar página em HTML, exemplo: artigo-nome-do-tema.html.
